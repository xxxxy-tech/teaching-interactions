04　用面积说明道理

以斜边 c 为边长作一个大正方形，面积是 c²。
大正方形里放四个全等的直角三角形，每个面积 ab/2，四个合起来 2ab。
中间空出一个小正方形，边长是 b − a，面积 (b − a)²。
两块面积相加：c² = 2ab + (b − a)² = a² + b²。
c² = 2ab + (b − a)² = a² + b²

教学说明

适用对象

北师大版八年级上册第一章「勾股定理」第一课时，或人教版八年级下册第十七章。用于定理的发现环节，而不是证明之后的应用练习。

教学目的

  • 经历发现过程：通过连续改变直角边，观察到 a²+b² 与 c² 始终相等，把「定理」还原成「一个可以被发现的规律」。
  • 发展几何直观：三个正方形的面积随边长同步变化，学生看到的是面积关系，而不只是三个数字。
  • 学习探究方法：操作 → 记录 → 比较 → 猜想 → 验证，完整走一遍数学探究的基本流程。
  • 理解证明的必要：几组数据只能支持猜想；用弦图做面积割补，才把「看起来成立」变成「一定成立」。

课堂用法（约 20 分钟）

  • 先让学生只拖动、不记录，说说「你注意到什么」。
  • 要求每人记录 3 组以上（含一组 a=b 的特殊情况），再投票选出猜想。
  • 猜想确认后追问：「再多记 100 组，能不能算证明？」引出弦图。
  • 用「下一步」逐步展开面积推导，每一步停一下让学生说理由。

设计说明

教科书上的勾股定理常常是「给出结论 + 给出证明」，学生缺少「为什么会有这个关系」的体验。这个页面把变量交给学生：a、b 一变，三个正方形的面积跟着变，而 a²+b² 与 c² 的差始终是 0——规律是被看见的，不是被告诉的。

页面的数值由 a、b 精确计算，c = √(a²+b²)，所以 c² 恒等于 a²+b²（显示为整数）。拖动与滑块都可用，便于鼠标与触屏。
